27. Remove Element

Sometimes removing elements doesn't mean actually deleting them.

LeetCode just wants the unwanted values out of the way. Convenient, right?

The trick? Two pointers: read and write.

For example:

nums = [3,2,2,3]  
val = 3

My approach:

- read → scans every element.
- write → tracks where the next valid element belongs.
- If nums[read] != val, copy it to nums[write] and increment write.
- Otherwise, skip it.

The result:

nums = [2,2,_,_]  
k = 2

The important insight:

We don't need to physically remove elements. We only need to make the first k positions valid.

Everything after index k - 1? Not our problem anymore.

Time: O(n)  
Space: O(1)

Reusable pattern: When filtering an array in-place, use one pointer to read and another to write.

No extra array. No shifting everything around. Just keep what matters.
