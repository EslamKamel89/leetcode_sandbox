74. Search a 2D Matrix
    
Binary search is great. But what if the array has two dimensions?
    
Apparently, we need binary search twice.
    
Given:
    
matrix = [[1,3,5,7], [10,11,16,20], [23,30,34,60]]
    
target = 3
    
My approach uses two-phase binary search:
    
1. Find the correct row
    
Compare the target with the first and last elements of the middle row.
    
- Target is smaller → search upper rows.
- Target is larger → search lower rows.
- Target is within the row's range → we found our candidate row.
    
2. Search inside that row
    
Run normal binary search to find the exact target.
    
For our example:
    
- Check [10,11,16,20] → target is smaller.
- Move to [1,3,5,7] → correct row!
- Binary search finds 3.
    
Result: True
    
Time: O(log m + log n) = O(log(m × n))  
Space: O(1)
    
Key takeaway: Sometimes a multidimensional problem becomes much simpler when you break it into smaller searches.
    
Two binary searches. One target. Zero unnecessary matrix scans.
