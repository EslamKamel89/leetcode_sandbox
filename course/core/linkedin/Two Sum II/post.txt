1. Two Sum
  
The legendary LeetCode problem that introduces developers to the power of hash maps.
  
The challenge? Find two numbers that add up to a target without checking every possible pair.
  
Given:
  
nums = [2,7,11,15]  
target = 9
  
Instead of using two nested loops, my solution uses one pass + a hash map.
  
Here's the idea:
  
- Visit 2 → Need 7 → Not found → Store {2: 0}
- Visit 7 → Need 2 → Found it!
  
Result: [0,1]
  
The core trick:
  
complement = target - num
  
If the complement exists in our hash map, we've found the pair.
  
Important detail: Check before storing the current number. This prevents using the same element twice.
  
Time: O(n) average  
Space: O(n)
  
Key takeaway: Sometimes optimizing an algorithm isn't about searching faster. It's about remembering what you've already seen.
  
Two nested loops? The hash map politely declined.
